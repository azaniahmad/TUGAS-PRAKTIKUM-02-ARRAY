## 📋 Deskripsi
Repository ini berisi kumpulan program dan tugas praktikum tentang penggunaan **Array** dalam pemrograman. Array merupakan struktur data fundamental yang digunakan untuk menyimpan kumpulan data dengan tipe yang sama dalam satu variabel.

## 🎯 Tujuan Pembelajaran
- Memahami konsep dan implementasi array
- Menguasai operasi dasar pada array (insert, delete, update, search)
- Mengimplementasikan algoritma sorting dan searching pada array
- Menyelesaikan permasalahan menggunakan array
